Проект комплексного проектирования, изоляции и развёртывания сетевой и серверной инфраструктуры компании на базе гипервизора **UTM/QEMU (ARM64)**. 

Включает программный маршрутизатор со шлюзом и NAT, авторитетный корпоративный DNS-сервер, автоматическую раздачу сетевых настроек, стек микросервисов в Docker с обратным прокси (Reverse Proxy).

## Реализованный стек и возможности

### 1. Маршрутизация и сетевой экран (Router)
* **IP Forwarding:** включена пересылка IPv4-пакетов между сетевыми интерфейсами на уровне ядра Linux (`net.ipv4.ip_forward = 1`).
* **NAT (Masquerading):** сконфигурированы правила `iptables` для подмены исходящих адресов внутренней сети `192.168.10.0/24` при обращении во внешний интернет.
* **DHCP-сервис (`dnsmasq`):** настроена автоматическая выдача IP-адресов (`.50` – `.150`), шлюза (`192.168.10.1`) и DNS (`192.168.10.10`).

### 2. Корпоративный DNS (Bind9 на Server)
* Сконфигурирована авторитетная зона прямого просмотра **`company.local`**.
* Добавлены A-записи для маршрутизатора, сервера приложений и веб-сервисов (`app`, `grafana`).
* Настроен безопасный форвардинг внешних DNS-запросов (Google/Cloudflare DNS).

### 3. Контейнеризация и Reverse Proxy (Docker Compose)
* **Nginx Reverse Proxy:** принимает трафик на 80 порту и маршрутизирует запросы по значению HTTP-заголовка `Host`:
  * `http://app.company.local` $\rightarrow$ перенаправляет в контейнер **Python Backend** (порт 8000).
  * `http://grafana.company.local` $\rightarrow$ перенаправляет в веб-интерфейс **Grafana** (порт 3000).
* **Стек мониторинга:**
  * **Node Exporter:** собирает системные метрики Linux-хоста (CPU, RAM, диск, сеть).
  * **Prometheus:** агрегирует метрики с интервалом скрейпинга 5 секунд.
  * **Grafana:** отображает визуальные дашборды производительности.

### 4. Автоматизация и Disaster Recovery (`scripts/backup.sh`)
* Написан Bash-скрипт с защитой `set -euo pipefail`.
* Скрипт архивирует конфигурации Bind9, Netplan, Nginx, Prometheus и `docker-compose.yml` в файл с отметкой времени (`tar.gz`).
* Реализована автоматическая ротация архивов: удаление бэкапов старше 7 дней с логированием в `/var/log/infra_backup.log`.
* Интегрирован в планировщик задач `cron` для запуска каждую ночь в 03:00.

## Верификация и тестирование сети

Для проверки всей цепочки с клиентской машины (`03-Client-PC`) разработан проверочный скрипт:

```bash
# Запуск теста с клиента:
./check_services.sh
```

```text

2. Проверка локального DNS (app.company.local): OK
3. HTTP-запрос к Python Backend: OK (200)
4. HTTP-запрос к мониторингу Grafana: OK (200/302)
=== ТЕСТИРОВАНИЕ ЗАВЕРШЕНО ===
```

## Структура репозитория

```text
├── README.md                  # Документация проекта
├── router/
│   ├── dnsmasq.conf           # Конфигурация DHCP-сервера
│   ├── iptables.rules         # Экспортированные правила фаервола и NAT

├── server/
│   ├── bind/                  # Зоны и настройки DNS-сервера Bind9
│   ├── docker/
│   │   ├── docker-compose.yml # Оркестрация сервисов и мониторинга
│   │   ├── nginx/             # Конфигурация Reverse Proxy
│   │   └── prometheus/        # Конфигурация скрейпинга метрик
│   └── netplan/               # Сетевые конфигурации Linux Server
├── client/
│   ├── resolv.conf            # Настройки клиентского DNS
│   └── check_services.sh      # Скрипт проверки доступности инфраструктуры
└── scripts/
    └── backup.sh              # Скрипт автоматического бэкапа и ротации
```
